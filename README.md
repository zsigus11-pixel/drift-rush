# DRIFT RUSH

Böngészőben futó, egyfájlos asset-függőség nélküli HTML5 Canvas drift arcade prototípus.

## Indítás
Nyisd meg az `index.html` fájlt modern böngészőben.

## Irányítás
- W / ↑: gáz
- S / ↓: fék / tolatás
- A / ← és D / →: kormányzás
- Space: kézifék / drift
- Mobilon: érintőgombok

## Szerkezet
- index.html — UI
- style.css — neon felület és reszponzivitás
- game.js — fizika, pályák, effektek, HUD

A grafika és hangok saját, procedurálisan rajzolt elemekre épülnek; nincs külső, jogvédett játékasset.
